# JANSETU AI — UI/UX DESIGN

## Design Direction
Google Material + Google Maps + modern civic technology.

Qualities:
- trustworthy
- calm
- accessible
- multilingual
- mobile-first citizen UX
- desktop-first government UX

## Visual System
Primary: deep civic blue
Secondary: green
Warning: amber
Critical: red
Neutral: white/light gray with dark text

Use non-color status labels too.

## Citizen Navigation
Home | Submit | My Requests | Updates

## Citizen Home
Headline:
"What does your community need?"

Primary CTA:
"Speak"

Secondary:
"Type a request"

Options:
- add photo
- use location

## Voice Flow
Tap microphone → record → transcript → AI understanding → confirmation → submit.

## AI Confirmation
Show:
- category
- problem statement
- location
- urgency

Buttons:
"Looks correct"
"Edit"

Never auto-submit AI interpretation.

## Request Status
Received → AI analyzed → clustered → priority analyzed → government review → project proposed → implementation → impact

## Government Dashboard
Filters:
country → region → district → sector → time

KPIs:
- requests
- hotspots
- high-priority issues
- recommended projects
- investment gap

Main:
interactive map + priority queue + trend charts

## Hotspot Detail
Show:
- requests
- affected population
- category
- infrastructure gap
- vulnerability
- investment
- funding gap
- priority score

## Project Detail
Sections:
- Why prioritized
- Evidence
- Recommended intervention
- Expected impact
- Cost/resources
- Risks
- Human review

## Score Visualization
Use horizontal factor bars:
Citizen Demand
Infrastructure Gap
Population Impact
Vulnerability
Urgency
Feasibility

## Policy Copilot
Suggested prompts:
- Which projects should we prioritize?
- Why is this district underserved?
- What fits within ₹10 Cr?
- What evidence supports this recommendation?
- What changed this month?

## Budget Simulator
Inputs:
budget
optimization objective
risk tolerance

Outputs:
selected portfolio
total cost
estimated beneficiaries
expected outcomes
unfunded high-priority needs
trade-offs

## Impact Dashboard
Baseline → Target → Actual
Show clear measurement source and whether values are observed or modeled.

## Accessibility
Keyboard navigation, semantic HTML, screen-reader labels, high contrast, large touch targets, transcripts, multilingual UI, non-color status indicators and low-bandwidth-friendly pages.

## Trust Labels
AI-assisted
Verified dataset
Estimated
Human review required
